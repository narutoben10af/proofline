# Privacy and Malaysian PDPA readiness

These documents are engineering readiness controls for the public/synthetic-fixture prototype. They are not legal advice, a privacy notice for publication, or evidence of Malaysian PDPA compliance.

- [PDPA readiness gap analysis](pdpa-readiness.md) — official-source effective dates, conditional applicability, current obligations, recommended controls, and unresolved prototype facts.
- [Prototype data-handling notice](prototype-data-handling-notice.md) — an intentionally non-publishable disclosure draft and the facts required before a section 7 notice can be issued.
- [Data-flow, retention, and deletion register](data-flow-retention.md) — current versus proposed flows, provider boundaries, TTL, exports, logs, and deletion scope.
- [Incident runbook](../security/incident-response.md) — containment, Malaysian breach-notification assessment, evidence, and recovery.
- [Application review checklist](../security/review-checklist.md) — the quick gate for backend, frontend, upload, export, and assistant pull requests.

Recheck the [Personal Data Protection Commissioner's official Act 709 hub](https://www.pdp.gov.my/ppdpv1/en/akta709/) before any release that widens processing.

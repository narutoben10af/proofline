# Architecture decision records

> This bootstrap-era directory is retained to preserve repository history. New and accepted decisions live in the canonical [`docs/architecture/`](../architecture/) directory; use its template for future ADRs.

Use architecture decision records (ADRs) for choices that materially affect Proofline's architecture, evidence traceability, data handling, privacy, security, or evaluation.

## Creating an ADR

1. Copy [`../architecture/template.md`](../architecture/template.md) into `docs/architecture/` with the next four-digit number and a short kebab-case title.
2. Fill in the context, decision, alternatives, and consequences.
3. Set the status to `Proposed` and include the ADR in the relevant pull request.
4. Change the status when the decision is accepted, superseded, or deprecated; do not erase the history.

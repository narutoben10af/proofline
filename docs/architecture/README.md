Architecture decision records (ADRs) capture consequential technical choices and their context.

## Adding an ADR

Copy [template.md](template.md), assign the next four-digit number, and open a pull request. Accepted ADRs are immutable historical records; supersede an earlier decision with a new ADR rather than rewriting its outcome.
